# 烽城戰場 PvPvE 原型

以 Three.js 製作的 1280×720 戰國戰場概念原型。瀏覽器側欄預覽已開啟。

畫面固定為 16:9，會按瀏覽器空間等比縮放，窄側欄也會完整保留橫向構圖。鏡頭約以 32.5 度俯視廣場，噴水池位於畫面偏上方、主角初始位置在其正下方。場景包含磚紋鋪面、水晶噴水池、座椅、右上民宅與秋色植栽；介面配置為左上狀態、右上小地圖、左下訊息和下方快捷列。

## 操作

- **WASD**：移動昭烈
- **空白鍵／J**：朝面向揮擊，按住可連續攻擊
- 靠近百姓會自動救援
- **重新開始**：重設戰局

兩名 AI 武將會自行移動、攻擊敵軍與其他武將。擊退敵兵、敵將、擊敗其他武將與救援百姓可獲得戰功。敵軍突破城門會減少城池耐久；兩分鐘後依戰功結算。

倍率目前是概念分值，尚未接入金額、下注或 RTP 結算。

## 本機啟動

在此資料夾執行 `node serve.mjs`，然後開啟 `http://127.0.0.1:4317/`。
